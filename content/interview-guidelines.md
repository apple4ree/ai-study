# 면접 답변 편집 기준

기초·심화 면접 200문항의 답변 구성은 [boost-devs/ai-tech-interview](https://github.com/boost-devs/ai-tech-interview)를 참고한다. 독립적으로 작성한 설명을 공식 문서·원 논문·대학 교재와 대조하며, 참고 저장소의 답변을 그대로 복사하거나 정답으로 가정하지 않는다.

## 문항 구성

1. 질문은 해당 개념을 이름으로 부르고, 정의·원리·비교·적용 조건을 설명하도록 작성한다.
2. 답변은 개념 소개, 핵심 용어 풀이, 원리와 동작, 구체적 예시로 연결한다. 세 줄 요약만으로 끝내지 않는다.
3. 비교가 핵심이면 표를, 계산 관계가 핵심이면 식과 기호 설명을, 구현 순서가 핵심이면 짧은 코드를 사용한다. 문항마다 불필요한 형식을 강제하지 않는다.
4. 심화 문항의 원래 상황은 `scenario`에 보존하고, 개념을 이해한 뒤 적용해보는 질문으로 제공한다.
5. 꼬리질문도 결론과 이유·조건을 함께 설명한다. 회사의 실제 기출·출제 빈도로 표현하지 않는다.
6. 원리 확인을 위한 문항별 참고자료와 기존 개념서 연결을 제공한다.

## 용어와 정확성

- 한 개념의 한국어 명칭을 일관되게 사용하고, 용어 풀이에서 영어·약어를 함께 정의한다.
- 규제(regularization), 특징 스케일링, 신경망 정규화 층의 서로 다른 의미를 구별한다.
- 기댓값·분산·우도·교차엔트로피·공분산·고유값 등 ML/DL의 전제 개념도 필요한 문항 안에서 설명한다.
- 기대 비용, 분할상환 비용, 최악 비용을 구별한다. 자료형 연산과 출력·메모리 비용을 생략하지 않는다.
- Python 언어와 CPython의 특정 버전·빌드를 구별한다. GIL·free-threaded 빌드·네이티브 연산의 조건을 명시한다.
- DB 제품별 격리 수준과 실제 실행 보장을 구별한다. CAP·ACID·복제 일관성처럼 같은 용어가 다른 맥락에서 쓰이는 경우 뜻을 밝힌다.
- p-value를 1종 오류 확률로 설명하지 않는다. 이항분포 PMF의 성공확률 지수는 관측 성공 횟수 x다. 원본 참고자료에서도 오류를 독립적으로 확인한다.

기존 문항 ID·분야·난도·우선 복습 지정과 개념서의 515개 절 경로를 유지한다. 이번 변경은 기존 200문항의 설명을 확장한 것이며, 참고 저장소의 모든 질문이나 수학·통계·Python 분야를 전부 수록한 것은 아니다.
