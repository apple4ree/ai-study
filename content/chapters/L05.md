## 구조는 데이터에 대한 가정을 코드로 넣는 방법이다

### 개념과 작동 원리

이미지의 이웃 픽셀은 물체의 작은 모양을 이루고, 문장의 단어는 순서에 따라 의미가 달라진다. 모든 입력을 길게 펼쳐 완전연결층에 넣을 수도 있지만, 데이터가 가진 구조를 무시하면 더 많은 자료와 파라미터가 필요할 수 있다. CNN은 가까운 위치의 패턴과 가중치 공유를, RNN은 이전 상태를 통한 순서를, Attention은 내용에 따른 가중합을 계산에 넣는다. 이런 미리 정한 구조적 성향을 귀납 편향이라고 한다.

구조가 맞으면 학습을 돕지만 틀리면 한계가 된다. 가까운 영역만 반복해서 보는 CNN은 층을 쌓거나 다른 연결로 넓은 관계를 다뤄야 하고, RNN은 순차 상태를 통과하는 긴 정보 경로를 가진다. Transformer는 긴 위치 사이를 직접 연결할 수 있지만 표준 dense attention에는 길이에 따른 비용이 있다. 어떤 구조가 무조건 상위라고 외우기보다 어떤 정보를 어떤 비용으로 연결하는지 보자.

### 구조적 가정과 실패 조건 비교

| 구조 | 공유하거나 제한하는 것 | 잘 맞는 패턴 | 한계 확인 질문 |
|---|---|---|---|
| CNN | 국소 필터를 위치에 공유 | 근처 값의 반복 모양 | 멀리 떨어진 관계를 얼마나 빠르게 연결하는가 |
| RNN | 시간별 같은 상태 갱신 | 순서와 스트리밍 | 긴 과거를 고정 크기 상태에 담을 수 있는가 |
| Self-attention | 내용에 따른 위치 간 가중합 | 토큰 간 직접 상호작용 | 길이에 따른 비용·위치 정보는 어떻게 처리하는가 |

**가중치 공유는 같은 기능을 여러 위치에 적용한다는 가정**이다. 입력 길이를 늘려도 파라미터가 그만큼 늘지 않을 수 있지만, 처리할 위치와 중간값은 늘어난다. 파라미터 효율과 실행 비용을 같은 것으로 읽지 않는다. 원본 Transformer의 구성과 구조적 동기는 [Attention Is All You Need](https://arxiv.org/abs/1706.03762)를 참고한다.

## CNN: 같은 필터를 여러 위치에 적용하기

### 개념과 작동 원리

1차원 입력 \[1,2,3,4\]에 필터 \[1,−1\]을 적용하자. 첫 위치에서 1×1+2×(−1)=−1, 다음에서 2×1+3×(−1)=−1, 마지막에서 3×1+4×(−1)=−1이다. 이 계산은 국소적인 차이를 읽는 예다.

딥러닝 라이브러리에서 convolution이라고 부르는 연산은 흔히 필터를 뒤집지 않는 교차상관 관례를 따른다. 학습되는 필터의 관점에서는 관례를 일관되게 쓰면 되지만 수식·코드를 비교할 때 구분해야 한다.

필터가 이동하는 간격이 stride이고, 경계 바깥에 값을 채우는 것이 padding이다. 입력 길이 n, kernel 크기 k, padding p, stride s, dilation 1인 경우 출력 길이는 floor((n+2p−k)/s)+1이다. n=5,k=3,p=1,s=2이면 floor((5+2−3)/2)+1=3이다. dilation을 사용하면 유효 kernel 크기가 달라지므로 이 단순 식의 가정을 바꿔야 한다.

2차원에서도 같은 원리다. 입력 영상이 32×32이고 3×3 kernel, padding=1, stride=1이면 출력 공간은 32×32를 유지한다.

입력 채널이 3, 출력 채널이 16이면 각 출력 채널마다 3개 입력 채널 전체를 섞는 3×3×3 가중치가 필요하다. 전체 가중치는 3×3×3×16=432개, 절편을 사용하면 16개가 추가돼 448개다.

같은 필터를 모든 위치에서 공유하므로 위치 수 32×32를 이 파라미터 수에 다시 곱하지 않는다.

작은 kernel을 여러 층 쌓으면 더 넓은 입력 영역의 영향을 받는다. stride=1인 3×3 convolution 두 층의 한 출력은 원본의 5×5 영역에 의존할 수 있다.

이를 receptive field라고 한다. pooling·stride는 공간 크기를 줄이고 더 큰 영역을 요약하지만 세부 위치 정보를 잃을 수 있다.

convolution의 이동 등변성은 입력을 이동하면 출력도 대응해 이동한다는 성질이며, 경계·stride의 영향은 별도 고려한다. 위치에 무조건 불변이라는 뜻은 아니다.

### 출력 크기·수용영역·연산량을 따로 계산하기

dilation=1이고 양쪽 padding p인 1차원 연산에서 출력 길이는 $\lfloor(n+2p-k)/s\rfloor+1$이다. n=7, k=3, p=1, s=2이면 4다. 실제로 필터 시작 위치가 두 칸씩 이동하며 4개 출력을 만든다.

| 계산 대상 | 대표 식·조건 |
|---|---|
| 출력 원소 수 | 공간 크기×출력 채널 |
| 파라미터 수 | $k_hk_wC_{in}C_{out}+C_{out}$, 절편 포함·일반 합성곱 |
| 곱셈 횟수 규모 | $H_{out}W_{out}k_hk_wC_{in}C_{out}$, 한 이미지 |
| 수용영역 | 해당 출력이 의존할 수 있는 입력 위치 범위 |

stride 1인 3×3 합성곱을 두 층 쌓으면 가운데 출력의 이론적 수용영역은 5×5다. 층마다 가장자리 1칸씩 넓어지기 때문이다.

그러나 파라미터 수와 실제 영향의 크기가 5×5 단일 필터와 같아지는 것은 아니다. 채널 혼합과 중간 비선형 연산도 다르다.

[D2L padding·stride 단원](https://d2l.ai/chapter_convolutional-neural-networks/padding-and-strides.html)의 정의와 크기 계산을 참고한다.

## RNN: 과거를 상태로 압축해 다음 계산에 전달하기

### 개념과 작동 원리

RNN은 h\_t=tanh(W\_x x\_t+W\_h h\_(t−1)+b)처럼 현재 입력과 이전 상태를 결합한다. 예를 들어 스칼라 상태에서 h₀=0, W\_x=W\_h=1,b=0, 입력 x₁=1,x₂=0이면 h₁=tanh(1)≈0.762이고 h₂=tanh(0.762)≈0.642다. 두 번째 입력이 0이어도 과거의 1이 상태를 통해 남는다. 같은 W\_x와 W\_h를 모든 시점에서 재사용하는 것이 시간축 파라미터 공유다.

학습에서는 시간별 계산을 펼친 그래프에서 역전파한다. h\_t가 h\_(t−1)에 의존하므로 앞 시점으로 가는 gradient에는 W\_h와 활성화 미분의 곱이 반복 등장한다. 스칼라 단순 예에서 매 단계 미분 계수가 0.5라면 10단계 전달된 크기는 0.5\^10≈0.000977배다. 1.5라면 1.5\^10≈57.7배가 된다. 실제 행렬 문제는 더 복잡하지만 긴 곱이 기울기 소실·폭주와 연결되는 이유를 보여준다.

LSTM은 별도 cell state와 gate를 사용해 정보의 유지·추가·출력을 조절한다. 핵심 갱신을 c\_t=f\_t⊙c\_(t−1)+i\_t⊙g\_t로 쓰면 f는 잊기 gate, i는 입력 gate, g는 새 후보 정보다.

c\_(t−1)=2,f\_t=0.9,i\_t=0.2,g\_t=0.5인 한 성분에서 c\_t=0.9×2+0.2×0.5=1.9다. gate 값은 고정 정책이 아니라 입력과 이전 상태에서 학습된 함수가 계산한다.

가산 경로는 정보 보존을 돕지만 모든 긴 의존성을 자동 해결하는 보장은 아니다.

### 상태 유지와 학습 그래프 길이를 구분하기

스칼라 선형 RNN $h_t=ah_{t-1}+x_t$에서 $\partial h_T/\partial h_0=a^T$다. a=0.5, T=10이면 약 0.000977이고 a=2이면 1024다. 실제 tanh RNN에서는 활성화 미분도 경로를 따라 곱해져 소실·폭주에 영향을 준다.

| 선택 | 앞으로 전달되는 것 | 뒤로 미분되는 범위 |
|---|---|---|
| 전체 BPTT | 이전 상태 | 펼친 전체 시간 구간 |
| truncated BPTT | 상태값은 계속 전달 가능 | 잘라 둔 구간 내부 |
| 상태 초기화 | 새로운 시작 상태 | 이전 구간과 연결 없음 |

상태를 detach하는 것은 **상태값을 0으로 만드는 것과 다르다.** 값을 다음 구간에 전달하면서 이전 그래프에 대한 미분만 끊을 수 있다. 기본 dense RNN의 T시점 순전파는 입력 차원 d·은닉 H일 때 O(T(dH+H²)) 시간이고, 전체 BPTT는 시간별 중간값 보관이 필요하다. 파라미터 저장량은 T배가 되지 않지만 활성값은 늘어난다.

## Attention: 어떤 내용을 얼마나 섞을지 입력에 따라 정하기

### 개념과 작동 원리

문장에서 ‘그것’이 가리키는 대상을 찾으려면 단순히 바로 앞 단어만 보는 것으로 부족할 수 있다. Attention은 현재 질문에 해당하는 query와 후보를 식별하는 key의 유사도를 계산하고, 그 비율로 value를 섞는다. Q,K,V는 대개 입력 표현에 서로 다른 선형 변환을 적용해 만든다. query·key는 가중치 결정에, value는 실제로 전달할 내용에 쓰인다는 역할 구분이 중요하다.

한 query에서 key와의 정규화 전 점수가 \[0,ln(3)\]이면 softmax 결과는 \[1/(1+3),3/(1+3)\]=\[0.25,0.75\]다. value가 \[2,10\]인 스칼라라면 출력은 0.25×2+0.75×10=8이다.

만약 value가 두 차원 \[2,0\]과 \[10,4\]라면 각 성분을 같은 가중치로 더해 \[8,3\]을 얻는다. 유사도가 높다는 사실이 출력값 자체가 크다는 뜻은 아니다.

key와 value를 분리한 이유가 여기에 있다.

행렬 계산으로 쓰면 다음과 같다.

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

query 수 n\_q, key 수 n\_k, key 차원 d\_k일 때 Q는 n\_q×d\_k, K는 n\_k×d\_k이므로 QKᵀ는 n\_q×n\_k다. softmax는 query별로 key 축에 적용하고, V가 n\_k×d\_v이면 최종 출력은 n\_q×d\_v다. √d\_k로 나누는 것은 성분 크기에 대한 적절한 가정 아래 내적 분산이 차원과 함께 커지는 것을 완화하여 softmax가 초기에 지나치게 뾰족해지는 문제를 줄이려는 설계다.

### Q·K·V의 shape와 가중합을 끝까지 계산하기

query 수 m, 후보 수 n, key 차원 dₖ, value 차원 dᵥ라 하자.

| 행렬 | 크기 | 역할 |
|---|---|---|
| Q | m×dₖ | 무엇을 찾는가 |
| K | n×dₖ | 무엇과 비교하는가 |
| V | n×dᵥ | 실제로 섞을 내용 |
| $QK^T$ | m×n | query별 후보 점수 |
| softmax 결과 A | m×n | 각 행의 합이 1인 가중치 |
| AV | m×dᵥ | 가중합 출력 |

한 query의 점수가 [0,ln(3)], value가 [(2,0),(0,4)]이면 가중치는 [0.25,0.75]다. 출력은 $(0.25\times2,0.75\times4)=(0.5,3)$이다. 높은 가중치의 후보에서 **key가 아니라 value**를 가져온다.

scaled dot-product에서 1/√dₖ는 성분들이 독립이고 비슷한 분산을 가진 단순 모형에서 내적 분산이 dₖ에 비례해 커지는 것을 완화한다. 모든 학습 상태에서 점수 분산을 정확히 1로 만드는 보장은 아니다. [D2L 점수 함수 단원](https://d2l.ai/chapter_attention-mechanisms-and-transformers/attention-scoring-functions.html)을 참고한다.

## Self-attention과 causal mask

### 개념과 작동 원리

Self-attention은 query·key·value가 같은 입력 시퀀스에서 나온다. 각 토큰이 다른 토큰의 정보를 내용에 따라 섞는다.

다만 위치 정보를 따로 주지 않은 self-attention은 토큰 순서를 자체적으로 특정하지 못한다. 입력을 같은 방식으로 순열하면 출력도 그에 따라 순열되는 구조이기 때문이다.

학습 가능한 위치 임베딩, sinusoidal 위치 정보, RoPE 같은 방식은 순서·상대 위치를 계산에 넣는 서로 다른 방법이다.

자기회귀 언어모델은 위치 t에서 다음 토큰을 예측할 때 미래 정답 토큰을 볼 수 없어야 한다. causal mask는 QKᵀ 점수에서 허용되지 않은 미래 위치에 −∞를 두어 softmax 후 가중치를 0으로 만든다.

일부 수치 구현은 충분히 작은 유한값 등으로 근사하기도 하며 masking 동작을 확인해야 한다. 길이 3에서 첫 위치는 key 1개, 두 번째는 2개, 세 번째는 3개를 볼 수 있다.

이는 훈련 시 미래 정답이 입력 텐서 안에 존재하더라도 순전파에서 미래 정답 정보가 현재 예측에 전달되지 못하도록 하는 계산 제약이다.

![고정 난수 Q·K로 softmax(QKᵀ/√d)를 계산했습니다. 각 행의 합은 1이며 causal mask 위쪽은 0입니다. 실제 모델의 attention 분석이 아닙니다.](/figures/L05.svg)

고정 난수 Q·K로 softmax(QKᵀ/√d)를 계산했습니다. 각 행의 합은 1이며 causal mask 위쪽은 0입니다. 실제 모델의 attention 분석이 아닙니다.

그림의 각 행은 한 query가 어느 key 위치에 가중치를 주는지 보여준다. 행의 합이 1인지, 미래 위치인 위쪽 삼각 영역이 0인지 먼저 확인하자. 첫 행이 자기 위치에만 가중치 1을 주는 것은 그 예시에서 다른 과거 토큰이 없기 때문이다.

뒤쪽 행에서 여러 과거 위치에 값이 분산되는 것은 허용된 범위 안에서 정보를 섞는 계산이다. 이 그림은 학습된 모델의 의미 해석을 입증하는 자료가 아니라 마스킹과 정규화의 원리를 보여주는 예시다.

### 세 토큰의 causal mask를 직접 읽기

세 위치가 자기 자신과 과거 위치를 읽도록 허용하면 다음 관계다. '허용'은 특정 API의 boolean 값이 아니라 수학적 관계를 뜻한다.

| query 위치 | key 1 | key 2 | key 3 |
|---|---|---|---|
| 1 | 허용 | 차단 | 차단 |
| 2 | 허용 | 허용 | 차단 |
| 3 | 허용 | 허용 | 허용 |

모든 원래 점수가 0이면 첫 행의 확률은 [1,0,0], 둘째는 [0.5,0.5,0], 셋째는 [1/3,1/3,1/3]이다. 차단 위치는 **softmax 전에** 제외하여 남은 위치에서 합이 1이 되게 한다. 확률을 만든 뒤 차단 위치만 0으로 바꾸면 재정규화하지 않는 한 다른 결과다.

다음 토큰 학습에서 위치 t의 입력 토큰을 보고 t+1을 예측하므로 자기 위치를 읽는 것은 허용할 수 있다. 정답 배열을 한 칸 이동하는 정렬 규칙과 mask를 함께 확인해야 한다. 위치 정보 없이 순서만 바꿨을 때의 equivariance와 causal mask가 부과하는 순서는 구분한다.

## Transformer block은 Attention 하나로 끝나지 않는다

### 개념과 작동 원리

Multi-head attention은 서로 다른 선형 투영으로 여러 가중합을 계산해 연결한 뒤 다시 출력 투영을 한다. head가 여러 개라는 것이 각각 문법·사실·감정 역할을 명시적으로 배정받았다는 뜻은 아니다. 모델이 서로 다른 표현 부분공간에서 정보를 섞을 수 있도록 한 구조다. 각 head 차원과 연결 후 모델 차원을 맞춰야 한다.

Transformer block에는 attention 외에 position-wise feed-forward network가 있다. FFN은 각 위치에 같은 MLP를 적용해 그 위치의 표현을 비선형적으로 바꾼다.

Attention이 위치 사이의 정보를 섞는다면 FFN은 섞인 표현의 특성을 변환하는 역할로 이해할 수 있다. Residual connection은 입력에 계산 결과를 더하는 경로이고 LayerNorm 등은 값의 규모를 조절한다.

normalization을 residual 앞에 두는지 뒤에 두는지는 구조별로 다르므로 모든 Transformer를 하나의 정확한 순서로 단정하지 않는다.

Encoder는 전체 입력 관계를 읽는 구조에 많이 쓰이고 decoder-only causal 모델은 다음 토큰 생성에 많이 쓰인다. Encoder-decoder 모델에서는 decoder query가 encoder 출력의 key·value를 읽는 cross-attention이 나타날 수 있다. ‘encoder는 이해, decoder는 생성’이라는 표현은 직관일 뿐, 실제 기능은 마스크·입출력·학습 목적까지 함께 정한다.

### residual 연결과 정규화 순서 구분하기

아래는 dropout을 생략한 한 하위층 F의 대표 형태다.

| 배치 방식 | 계산식 | 정규화가 놓인 위치 |
|---|---|---|
| Post-LN | LayerNorm(x+F(x)) | 합친 뒤 |
| Pre-LN | x+F(LayerNorm(x)) | 하위층 입력 앞 |

[LayerNorm 위치에 관한 원 논문](https://arxiv.org/abs/2002.04745)은 이 차이를 분석한다. 둘은 같은 식이 아니다. residual 합을 하려면 x와 F의 출력 크기가 같아야 한다. FFN이 내부 차원을 d→d_ff로 넓히더라도 다시 d로 줄이는 이유 중 하나다.

순수 residual 식 y=x+F(x)의 Jacobian은 I+J_F다. 이는 항등 경로를 제공하지만, 다른 정규화·활성화와 전체 네트워크를 포함해 어떤 경우에도 gradient가 안전하다는 보장은 아니다. [D2L Transformer 구성](https://d2l.ai/chapter_attention-mechanisms-and-transformers/transformer.html)을 원 논문의 블록과 비교해서 읽는다.

## 비용과 병렬성은 학습과 생성에서 다르게 나타난다

### 개념과 작동 원리

표준 dense self-attention의 score 행렬은 n×n이다. n=128이면 16,384개, n=512이면 262,144개로 길이를 4배 늘렸을 때 원소 수는 16배가 된다.

실제 attention 계산 시간에는 feature 차원과 다른 연산도 들어가며, 효율적인 커널은 score 전체를 저장하지 않는 방식으로 메모리 사용을 줄일 수 있다. 따라서 이 원소 수를 모든 구현의 실제 GPU 메모리와 동일시하면 안 된다.

RNN은 이전 상태를 기다리는 순차 의존이 있어 시간축 병렬 학습에 제약이 있다. Transformer는 훈련에서 정답 시퀀스를 제공하고 causal mask를 적용해 여러 위치를 병렬 계산할 수 있다.

그러나 자기회귀 생성에서는 새 토큰을 만든 뒤 그것을 다음 입력에 넣는 의존이 남는다. 학습이 병렬적이라는 사실이 전체 생성도 한 번의 호출로 끝난다는 뜻은 아니다.

이전 토큰의 key·value를 재사용하는 KV cache는 L07에서 이 비용과 연결해 설명한다.

### prefill·decode·KV cache의 비용을 나누기

| 구간·대상 | 표준 dense attention의 대표 비용 | 해석 |
|---|---|---|
| 길이 n을 한 번 처리하는 attention 곱 | O(n²d) | 모든 query·key 쌍과 value 가중합 |
| 선형 투영·FFN | 흔히 O(nd²) 규모 | attention 비용과 별도 |
| KV cache 사용 후 새 토큰 하나 | attention 부분 O(nd) | 새 query가 과거 n개 key·value를 읽음 |
| 일반 MHA의 KV 저장 | 층별 O(nd) | 과거 key와 value를 보관 |

B=1, 층 수 L=2, 길이 n=4, 모델 차원 d=8이고 key·value 총 차원이 각각 d인 일반 MHA라면 cache 원소는 $2BLnd=128$개다. 원소당 2바이트면 256바이트다. 메타데이터·할당 여유·다른 활성값은 제외한 계산이다. GQA·MQA 등 다른 공유 구조에서는 식이 달라진다.

[공식 KV cache 설명](https://huggingface.co/docs/transformers/cache_explanation)에서 재사용하는 상태와 autoregressive 계산을 확인할 수 있다. **KV cache는 계산 재사용이며 모델 학습 기억을 추가하는 기능과는 다르다.** FlashAttention은 full score 행렬의 고비용 메모리 왕복을 줄이는 정확 attention 구현으로, 길이에 따른 모든 산술 비용을 자동으로 선형으로 바꾼다는 뜻은 아니다. [원 논문](https://arxiv.org/abs/2205.14135)의 IO 비용과 수학적 attention을 구분한다.

## Head를 늘리는 것과 모델 차원을 늘리는 것은 다르다

### 개념과 작동 원리

모델 차원 d\_model=512, head 수 8, head별 key·value 차원 64라면 연결한 표현은 8×64=512차원이다. 각 토큰에서 Q·K·V를 만드는 전체 투영은 흔히 512×512 가중치를 각각 사용하고, 연결 후 출력 투영에도 512×512가 들어간다.

절편을 제외하면 네 행렬은 4×512²=1,048,576개 파라미터다. 이 기본 구성에서 모델 차원을 고정한 채 head를 나누는 것은 매 head마다 독립된 512차원 전체 모델을 8개 복제하는 것과 다르다.

구조별로 차원·KV 공유 방식이 달라질 수 있으므로 실제 정의를 확인한다.

또 attention 가중치가 높은 토큰을 보았다는 사실만으로 그 토큰이 최종 답의 인과적 이유라고 확정할 수 없다. Value 투영·다른 head·residual·FFN·후속 층이 결과를 바꾸기 때문이다.

가중치 시각화는 어떤 정보 결합이 일어났는지 관찰하는 한 창이고, 설명 가능성을 주장하려면 입력 개입·대조 실험 등 추가 근거가 필요하다. 내부 행렬을 그림으로 그렸다는 사실과 모델의 판단 이유를 증명했다는 주장을 구분하자.

### 고정 모델 차원에서 head를 나누는 계산

모델 차원 d=8, head 수 h=2, head별 dₖ=dᵥ=4라면 head별 출력 두 개를 연결한 차원은 8이다. head 수를 4로 바꾸면서 각 차원을 2로 줄여도 연결 차원은 8이다.

```py
model_dim = 8
for heads in [2, 4]:
    head_dim = model_dim // heads
    assert heads * head_dim == model_dim
```

일반적인 full multi-head 구성에서 Q·K·V·출력 투영의 가중치 수는 절편 제외 4d²다. d=8이면 256개다. 전체 투영 차원을 d로 고정하면 head 수만 늘려도 이 수가 곧바로 h배가 되지는 않는다. 반면 명시적으로 저장하는 head별 n×n attention 행렬의 합은 h에 비례한다.

**복습 문제:** h=4, d=8인 구성에서 각 head의 출력이 2차원이면 연결 후 차원은? 4d² 투영 가중치는?

<details><summary>풀이</summary>

연결 후 4×2=8차원이며 절편 제외 가중치는 4×8²=256개다. 각 head가 8차원을 유지하는 다른 설계라면 출력·투영 크기부터 달라지므로 같은 공식으로 비교하면 안 된다.

</details>

## 핵심 정리

CNN은 국소 필터와 위치별 가중치 공유로 격자 구조를 이용한다. RNN은 상태를 재사용하여 순서를 전달하고 LSTM은 gate로 정보 흐름을 조절한다.

Attention은 query·key로 가중치를 정해 value를 가중합한다. Self-attention의 순서 정보와 미래 차단은 위치 표현과 causal mask가 제공한다.

Transformer는 attention·FFN·residual·normalization을 결합한 구조다. 구조별 계산 비용은 길이·차원·학습 여부·커널 구현까지 포함해 해석해야 한다.

## 복습 문제와 풀이

**1. 입력 영상 28×28, kernel 5×5, padding 0, stride 1이면 출력 공간 크기는? 입력 채널 1, 출력 채널 8, 절편 사용 시 파라미터 수는?**

<details>
<summary>풀이 보기</summary>

한 축 출력은 floor((28−5)/1)+1=24이므로 24×24다. 가중치는 5×5×1×8=200개, 절편은 8개여서 총 208개다. 출력 위치 수를 파라미터 수에 곱하지 않는다.

</details>

**2. attention 가중치 \[0.2,0.3,0.5\]와 value \[1,4,−2\]의 출력은?**

<details>
<summary>풀이 보기</summary>

0.2×1+0.3×4+0.5×(−2)=0.2+1.2−1=0.4다. 가중치는 음수가 없고 합이 1이지만 value에는 음수가 있을 수 있으므로 출력은 확률이 아니다.

</details>

**3. causal mask만 있으면 위치 정보 없이 문장의 순서를 충분히 표현하는가?**

<details>
<summary>풀이 보기</summary>

causal mask는 누가 누구를 볼 수 있는지 제한한다. 위치 표현은 거리·순서 정보를 표현에 반영한다. 마스크가 경계 정보를 일부 제공할 수 있어도 두 장치의 역할은 같지 않으며 일반적인 Transformer에서 별도 위치 설계를 사용하는 이유를 없애지 않는다.

</details>
